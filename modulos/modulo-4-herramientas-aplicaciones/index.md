# Módulo 4: Herramientas y Aplicaciones Prácticas

Maximizando la productividad individual y técnica con IA.

**Duración:** 75 min

## Estructura del módulo

| Sección | Contenido |
|---------|-----------|
| **4.1** Ecosistema de herramientas | ChatGPT, Gemini, Perplexity y NotebookLM |
| **4.2** Fundamentos de prompting | Las 3 técnicas maestras para instrucciones perfectas |
| **4.3** Desarrollo asistido con Copilot | VS Code + GitHub Copilot |
| **4.4** Agentes y automatización | MCP, Frameworks y Copilot Studio |

## Objetivos de aprendizaje

Al completar este módulo serás capaz de:

- Elegir la herramienta de IA adecuada para cada tarea
- Aplicar las tres técnicas maestras de prompting
- Usar GitHub Copilot en el flujo de desarrollo
- Comprender qué son los agentes de IA y el protocolo MCP
- Conocer las capacidades de Copilot Studio
