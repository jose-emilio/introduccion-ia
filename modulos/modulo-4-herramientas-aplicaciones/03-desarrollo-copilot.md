# 4.3 Desarrollo Asistido con Copilot

> Más del 46% del código nuevo en GitHub hoy ya lo escriben los modelos.

## VS Code + Copilot

| Función | Descripción |
|---------|-------------|
| **Inline Suggestions** | Ghost text que completa tu código en tiempo real |
| **Copilot Chat en IDE** | Conversación directa para explicar funciones o generar tests |
| **Terminal Chat** | Explica comandos y ayuda a depurar errores |

## Comandos de Contexto Maestros

| Comando | Función |
|---------|---------|
| `@workspace` | Contexto de todo el proyecto actual |
| `#file` | Referencia un archivo específico para análisis |
| `/terminal` | Asistencia con errores de consola |

## Mejores Prácticas para Devs

1. **Divide las tareas en partes pequeñas** — Pide funciones pequeñas y bien acotadas
2. **Nombra bien tus variables y funciones** — Copilot usa los nombres para inferir contexto
3. **Verifica siempre la seguridad del output** — Revisa inyecciones SQL, exposición de datos y autenticación
