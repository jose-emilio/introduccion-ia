# Módulo 2: Fundamentos de la IA

Los pilares tecnológicos de la transformación cognitiva: Machine Learning, Deep Learning, NLP y Automatización Inteligente.

**Duración:** 45 min

## Estructura del módulo

| Sección | Contenido |
|---------|-----------|
| **2.1** Machine Learning | Aprendizaje automático, tipos y casos de uso empresariales |
| **2.2** Deep Learning | Redes neuronales profundas y el caso DALL-E |
| **2.3** NLP y procesamiento del lenguaje | El puente entre humanos y máquinas, caso ChatGPT |
| **2.4** Automatización basada en IA | De flujos rígidos a sistemas inteligentes |

## Objetivos de aprendizaje

Al completar este módulo serás capaz de:

- Comprender la jerarquía IA → ML → DL
- Diferenciar aprendizaje supervisado, no supervisado y por refuerzo
- Explicar qué son las redes neuronales profundas
- Identificar aplicaciones de NLP en el entorno empresarial
- Distinguir automatización tradicional de automatización basada en IA

## Resumen conceptual

| Concepto | Descripción |
|----------|-------------|
| **Machine Learning** | Algoritmos que identifican patrones en datos históricos |
| **Deep Learning** | Redes neuronales profundas para datos no estructurados |
| **NLP** | Procesamiento y generación de lenguaje humano |
| **Human-in-the-Loop** | Supervisión humana estratégica en procesos automatizados |
