# 2.2 Deep Learning

## ¿Qué es el Deep Learning?

El Deep Learning es una evolución avanzada del Machine Learning que utiliza redes neuronales artificiales con múltiples capas apiladas. Su nombre proviene de la «profundidad»: la cantidad de capas intermedias que procesan la información.

Su mayor ventaja es la **extracción automática de características**: no necesita que un humano estructure los datos de entrada.

| Tipo de dato | Aplicación |
|-------------|------------|
| Imágenes y vídeo | Reconocimiento visual sin preprocesado manual |
| Audio y voz | Transcripción y síntesis de lenguaje hablado |
| Texto no estructurado | Análisis de grandes volúmenes de documentos |

## Arquitectura de una Red Neuronal Profunda

```
Capa de Entrada → Capas Ocultas → Capa de Salida
```

Una red «superficial» tiene 1 o 2 capas ocultas. Una red «profunda» puede tener decenas o centenares.

## Los Dos Combustibles del Deep Learning

1. **Big Data Corporativo y Global:** Millones de ejemplos para ajustar millones de parámetros internos.
2. **Capacidad de Cómputo (GPUs):** Las tarjetas gráficas y la nube hacen viable el cómputo en horas en lugar de siglos.

## Deep Learning en Acción: DALL-E

DALL-E traduce una descripción textual en lenguaje natural en una imagen completamente nueva. Ha aprendido la correspondencia estadística entre millones de imágenes y sus descripciones textuales.
