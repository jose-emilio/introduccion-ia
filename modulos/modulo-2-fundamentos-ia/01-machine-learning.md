# 2.1 Machine Learning

## Programación Tradicional vs. Machine Learning

| | Programación Tradicional | Machine Learning |
|---|---|---|
| **Entradas** | Datos + Reglas escritas por humanos | Datos históricos + Resultados deseados |
| **Salida** | Resultado estático y predecible | El algoritmo descubre las reglas autónomamente |
| **Adaptación** | Requiere reprogramación manual | Se adapta y mejora con más datos |

## ¿Cómo «Aprende» un Algoritmo de ML?

El término «aprendizaje» se refiere a un proceso iterativo de ajuste estadístico:

```
Ingesta → Optimización → Inferencia
```

Cada iteración reduce el margen de error del modelo. Tras miles o millones de iteraciones, el algoritmo ha «aprendido» a reconocer patrones.

## Tipos de Machine Learning

| Tipo | Descripción | Ejemplo |
|------|-------------|---------|
| **Aprendizaje Supervisado** | Se entrena con datos etiquetados por humanos | Predecir si un cliente abandonará la suscripción |
| **Aprendizaje No Supervisado** | Recibe datos sin etiquetas y descubre estructuras ocultas | Segmentar clientes en grupos de comportamiento |
| **Aprendizaje por Refuerzo** | Aprende mediante prueba y error con recompensas | Optimización de rutas logísticas en tiempo real |
